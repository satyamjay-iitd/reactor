Expand description

The ActorProcess trait defines the processing logic for an actor that transforms input messages into one or more output messages.

§Example

ⓘ
struct Incrementer;

impl ActorProcess for Incrementer {
    type IMsg = i32;
    type OMsg = i32;

    fn process(&mut self, input: i32) -> Vec<i32> {
        vec![input + 1]
    }
}
